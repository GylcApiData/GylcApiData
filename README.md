# ¡Hola! Soy Yair 👋

Desarrollo soluciones para conectar la operación de almacenes con SAP Business One.

## 💻 Tecnologías

- **Escritorio** · Visual Basic .NET, Windows Forms y .NET Framework.
- **Web** · PHP, JavaScript, jQuery, HTML y CSS.
- **Bases de datos** · SQL Server y SAP HANA.
- **Integraciones** · SAP Business One DI API y servicios web.
- **Herramientas** · Visual Studio, Git, GitHub y Postman.

## 📦 Proyectos

### Administrador WMS

Aplicación de escritorio para administrar usuarios, permisos, dispositivos, formatos y parámetros del WMS, con integración a SAP Business One.

### WMS API DATA WEB

Plataforma web para procesos de inventario, entradas, entregas, transferencias, picking y packing.

## 🎯 Mi enfoque

Crear herramientas que faciliten el trabajo diario, reduzcan la captura manual y conecten los movimientos del almacén con la información de SAP.
